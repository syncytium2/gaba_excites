## None of the current cells rebounds

500 ms hyperpolarizing steps, spikes counted in the 1 s after release (`src/core` API, 2026-10-19): the GnRH cell
(−10 to −60 pA from its −6 pA hold), the pyramidal cell and the fast-spiking cell (−200 to −1000 pA) all relax to

## The candidate: the LTS pyramidal cell of ModelDB 123623

The low-threshold-spike cell in the same ModelDB entry as our pyramidal and fast-spiking cells (Pospischil et al.
2008, `demo_PY_LTS.hoc`, template `sPYr_template`), originally Destexhe, Contreras & Steriade 2001, *Neurocomputing*
38:555. It is the pyramidal cell's `hh2` INa/IK and `im` M current plus Huguenard's T-type calcium current
(`IT_huguenard.mod`) and calcium decay (`cadecay_destexhe.mod`). The demo's parameters: `gcabar_it = 4e-4`,
`gkbar_im = 3e-5` (`taumax_im = 1000`), `g_pas = 1e-5`, `e_pas = −85`, `gnabar_hh2 = 0.05`, `gkbar_hh2 = 0.005`,
`vtraub_hh2 = −55`, diam = L = 96 µm, `ek = −100`, `ena = 50`, 36 °C, `v_init = −84`. Read the template and the two
.mod files for the rest; do not take these from this note alone.

**Checked in NEURON (original mechanisms, commit `8dfc13f`, the same commit our oracle uses), dt 0.01 ms,
500 ms steps from 1100 ms, spikes in the 1 s after release:**

| Held at | Step | During | After release |
|---|---|---|---|
| −64 mV (+60 pA) | 0 | 0 | 0 |
| −64 mV | −50 pA (to −80 mV) | 0 | 1, 88 ms after |
| −64 mV | −100 pA (to −99 mV) | 0 | 2, 112 ms after |
| −66 mV (+50 pA) | −50 pA (to −84 mV) | 0 | 1, 93 ms after |
| −71 mV (+30 pA) | −100 pA | 0 | 1, 284 ms after |
| own rest −84 mV (0 pA) | −50 to −300 pA | 0 | 0 |

At its own rest (−84 mV) the T channels are already de-inactivated: it bursts on depolarization (100 pA → 2
spikes, 150 pA → 4) and does not rebound. Held near −65 mV, the T channels are inactivated; a hyperpolarizing step
de-inactivates them and release fires the cell. **That is the lesson: hyperpolarization excites, and only from the
right resting potential** — the same "where is rest?" point the GnRH tour ends on. A GABA PSP with E_GABA near
−80 mV should do what the step does; check that as part of the work.

The NEURON check, as run (from a clone of ModelDBRepository/123623 after `nrnivmodl *.mod`, NEURON from pip in a venv,
per `tools/neuron_oracle.py`'s docstring):

```python
from neuron import h
h.nrn_load_dll("arm64/.libs/libnrnmech.dylib"); h.load_file("stdrun.hoc"); h.xopen("sPYr_template")
s = h.sPYr().soma[0]
s.gcabar_it = 4e-4; s.gkbar_im = 3e-5; s.g_pas = 1e-5; s.e_pas = -85; s.gnabar_hh2 = 0.05; s.gkbar_hh2 = 0.005
h.celsius = 36; h.dt = 0.01
st = h.IClamp(s(0.5)); st.delay = 1100; st.dur = 500
hold = h.IClamp(s(0.5)); hold.delay = 0; hold.dur = 1e9
v = h.Vector().record(s(0.5)._ref_v); t = h.Vector().record(h._ref_t)
def run(amp_nA):                      # spikes = upward crossings of -20 mV
    st.amp = amp_nA; h.finitialize(-84); h.continuerun(2600)
    V, T = list(v), list(t)
    sp = [T[i] for i in range(1, len(V)) if V[i-1] < -20 <= V[i]]
    return [x for x in sp if 1600 <= x < 2600]    # after release
for hp in [0.03, 0.05, 0.06]:
    hold.amp = hp
    for a in [0, -0.05, -0.1, -0.2]: print(hp, a, run(a))
```

## How to build it (AGENTS.md's rules apply)

- A worktree and branch first (`git worktree add ../gaba_excites-worktrees/lts-cell -b lts-cell`).
- **Two new channel objects** satisfying `Channel` (`src/core/channels.ts`): the Huguenard T current and the
  Destexhe calcium decay. The solver must not learn about them. The GnRH model already has a calcium pool and its
  own T current (Adams 2018) — read how it is done, but port Huguenard's equations as written in the .mod files.
- **The cell entry in `src/core/models.ts`**, with ranges, defaults and a `blurb`/`validation` line.
- **Extend `tools/neuron_oracle.py` with an `lts` cell** (it already has `rs` and `fs`; add the two .mod files to
  its nrnivmodl line), write `src/core/oracle/neuron_lts.json`, and make `src/core/oracle.test.ts` hold the port to
  NEURON's spike times — including the rebound protocol, not only depolarizing steps. This is what lets the site
  call it validated like the pyramidal cell.
- **Presets scoped to the cell**, among them a rebound preset (held near −65 mV, a hyperpolarizing step) whose
  note quotes numbers a test pins. Maybe a tour part later; ask the owner.
- **`lit/sources.json` entries** for Destexhe, Contreras & Steriade 2001 and for the T current's source (Huguenard &
  McCormick 1992, as the .mod file cites — check it), with transcription notes; then `node scripts/lit.ts`.
- **`docs/process.md`** entry; README, `public/methods.html` and `public/llms.txt` mention the fourth cell.
- `npm test`, `npx tsc -b`, `node scripts/screenshot.mjs` (it drives the amplifier in both modes and fails if the
  amplifier moves on a mode switch). Deploy only with `npm run deploy`, from main, after the owner says so.
