# Qiu et al. 2024: the arcuate kisspeptin (KNDy) cell, code against paper

Qiu J, Voliotis M, Bosch MA, Li XF, Zweifel LS, Tsaneva-Atanasova K, O'Byrne KT, Rønnekleiv OK, Kelly MJ (2024)
Estradiol elicits distinct firing patterns in arcuate nucleus kisspeptin neurons of females through altering ion
channel conductances. *eLife* 13:RP96691. doi:10.7554/eLife.96691 · PMC11643640.

This is everything `src/core/kndy.ts` and `linearPool` in `src/core/pools.ts` take, where it came from, and where
the paper and the authors' code part ways. **The port follows the code.**

  name is misspelled in the archive), from Software Heritage, `swh:1:dir:585910cdf67ffc5ccef5aec83674b19da1aca8b1`,
  archived 2024-12-09. The paper's own link, `git.exeter.ac.uk/mv286/kiss1-arcuate-neuron-model`, refused

- **The paper's table**: Appendix 1—table 1, from the PubMed Central full text (CC BY), and from

## The model, as the code writes it

One compartment, units nS, pF, pA, mV, ms, µM. Every steady state is `1/(1 + exp((V½ − V)/k))`: activation has
k > 0, inactivation k < 0.

| current | equation | what is unusual |
|---|---|---|
| transient Na⁺ | g·m∞(V)·h·(V − E_Na) | activation instantaneous and first power; inactivation τ a constant 4.5 ms |
| persistent Na⁺ | g·m∞(V)·h·(V − E_Na) | inactivation τ 250 ms |
| A | g·m·h·(V − E_K) | Mendonça's Kv4 steady states (V½ −30/−55.1 mV, k 10/−11.4) with constant τ, 10 and 20 ms |
| BK | g·b(V, Ca)·(V − E_K) | instantaneous; half-point V0 − 18·ln(Ca/1.5 µM); zero when Ca ≤ 0 |
| SK | g·Caⁿ/(Caⁿ + Kⁿ)·(V − E_K) | instantaneous |
| M | g·m·(V − E_K) | τ a constant 10 ms; the code's comment calls this gate "Delayed-rectifier" |
| h | g·(p·h1 + (1 − p)·h2)·(V − E_h) | two gates, τ 80 and 310 ms |
| T | g·m∞(V)·(f·h1 + (1 − f)·h2)·(V − E_Ca) | activation instantaneous, first power |
| Ca (L, N, P/Q, R) | g·m·h·(V − E_Ca) | |
| TRPC5 | g·R/(1 + exp(−(Ca − 0.6)/k))·(V − E_TRPC5) | R: an effector NKB activates; half active with no NKB |
| GIRK | g·q·R₂·(V − E_K) | g = 0, and R₂ stays 0 without agonist: silent |
| K⁺ leak | g·(V − E_K) | |
| Ca²⁺ "leak" | g/(1 + exp((20 − V)/10))·(V − E_Ca) | voltage-gated in the code; the paper writes a plain leak |

Calcium: `dCa/dt = −γ·(0.9·I_TRPC5 + I_T + I_Ca + I_leak,Ca) − d·Ca`.

**There is no delayed-rectifier K⁺ current.** The A, M, BK and SK currents repolarize the spike, and the action
potential is wide: half-width 8.2 ms in OVX and 11.2 ms in OVX+E2 at 20 pA, measured on the port. Recorded
kisspeptin-neuron spikes are about 1 ms. This matters to anything that depends on what happens during a spike.

Starting state: all zeros, both effectors inactive, then 20 s at rest (the script). Solver: `ode45`, maximum step
1 ms, default tolerances. The paper's main text says ode45; its appendix says "a standard fourth-order
Runge–Kutta method".

Estradiol (`params_OVXE2`) changes nine values: gT 0.666 → 4.995, gCa 2.1 → 2.8, gh 0.5617 → 11.234, gTRPC5 8.4 →
1.68, gBK 13.5 → 20, Cm 23.13 → 19.5, gA 60 → 35, gleak 3.5 → 3.65, gM 0.23 → 1.23.

## What the two make, both run in the authors' own right-hand side

`tools/kndy_oracle.m` runs three sources in both states. Tight tolerances (RelTol 1e-9); 5 s steps from rest.

| source | state | rest, mV | Rin, MΩ (−2 pA, 5 s) | spikes in 5 s at 10 / 20 / 60 / 120 pA |
|---|---|---|---|---|
| code, as archived | OVX | −66.36 | 389 | 35 / 63 / 112 / 231 |
| code, as archived | OVX+E2 | −69.98 | 250 | 40 / 82 / 86 / 186 |
| table's values, code's equations | OVX | −71.11 | 169 | 0 / 0 / 0 / 1 |
| table's values, code's equations | OVX+E2 | −72.84 | 136 | 0 / 0 / 1 / 1 |
| table and the paper's leak equation | OVX | −55.55 | 21 | 0 / 0 / 0 / 0 |
| table and the paper's leak equation | OVX+E2 | −56.87 | 25 | 0 / 0 / 0 / 0 |

- **The table's cell does not fire repetitively**: one spike at most. With the paper's leak equation as written,
  a plain 4 nS leak to +121.6 mV, the cell sits near −55 mV with about 21 MΩ and calcium near 2 µM.
- So the code, not the table, is what produced a firing cell. The port follows the code, and `kndy.test.ts`
  holds it to the code's numbers: rest in all six cells to 0.001 mV, the code cells' input resistance to 0.5%,
  and every spike of the OVX family from 5 to 60 pA.
- **The code does not reproduce its own comment.** `Kiss1_model_scirpt.m` carries `%-68.9241  -70.9198` above the
  run that prints the two resting potentials. Run unchanged in MATLAB R2025b it prints −66.3638 and −69.9770.
  The comment is presumably from an earlier parameter set.
- Whether the archived parameters are the ones behind the paper's figures is not known. The Figure 13 parameter
  sweeps are not in the archive. That is a question for the authors, and asking is the owner's call.

## Input resistance is not the leak

The model's leak is 3.5 nS, which alone would be 286 MΩ. Measured on the cell at rest:

| how | MΩ |
|---|---|
| 1/g_leak | 286 |
| 1/(sum of every open conductance at rest, 5.96 nS) | 168 |
| slope of the steady-state I–V | 414 |
| current clamp, −2 pA for 3 s | 389 |
| current clamp, −20 pA for 3 s (the size Mendonça 2018 used) | 298 |
| voltage clamp, −2 mV, at 10 ms | 425 |
| voltage clamp, −2 mV, at 3 s | 358 |

The steady slope is higher than the leak alone because inward currents that grow with depolarization (persistent
Na⁺, T, TRPC5 through calcium) subtract from it. Mendonça et al. 2018 report 1.34 ± 0.69 GΩ in male arcuate
kisspeptin neurons; this model, of females, is three to four times leakier by any of these measures.
