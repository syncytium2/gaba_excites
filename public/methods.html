1. The cell

The cell is the regular-spiking (RS) pyramidal neuron of Pospischil et al. (2008), the most common electrophysiological class of excitatory neuron in neocortex. It has a single isopotential compartment with three voltage-dependent currents: a transient sodium current and a delayed-rectifier potassium current, both in the Traub–Miles formulation, which make the action potential; and a slow, non-inactivating M-type potassium current, which produces spike-frequency adaptation. There is no calcium current and no calcium-activated potassium current.

The kinetics and parameters are transcribed from the model's ModelDB entry (accession 123623): the mechanisms HH_traub.mod and IM_cortex.mod, and the cell template sPY_template. Temperature is 36 °C, where both temperature factors in those files equal 1.

As published, this cell has Cm = 289.5 pF and a resting potential of −70.57 mV. Its input resistance at rest is 32.1 MΩ; the template's comment gives 34 MΩ, which is the leak alone, and the channels open at rest bring it down to 32.1. That is low for a pyramidal cell recorded in a slice, where 100–300 MΩ is common, and it is low on purpose: the RS model was fit partly to recordings in vivo, where background synaptic activity holds the membrane in a high-conductance state. The simulator opens on these published values; the Rin and Cm controls move away from them.

2. Rin, Cm and Ihold

A model file specifies densities per unit area. An experimenter reads whole-cell quantities off the amplifier. The simulator takes the whole-cell quantities and maps them onto the model:

  • Cm sets the size of the cell. Area = Cm / (1 µF/cm²). The active channel densities are held fixed, so a larger cell has proportionally more of every channel. Because Rin is held where you set it, the leak density falls as the cell grows. The result is that rheobase is set mostly by Rin, not by Cm: on the published cell it is 590, 561 and 551 pA at Cm = 145, 290 and 579 pF, but 129 pA if Rin is raised to 150 MΩ. Cm changes the speed: τm, the latency to the first spike, and how fast the voltage follows a synaptic input.
  • Rin is the input resistance you would measure at rest: the inverse slope of the steady-state current–voltage relation at the resting potential, active conductances included. The simulator finds the leak conductance gL that makes this true, by bisection. It does not use gL = 1/Rin, because channels open at rest (mainly the M current) conduct too, and a knob labeled Rin should give back Rin when you measure it. If the requested Rin is so high that the channels open at rest alone conduct more than 1/Rin, no leak can produce it; the simulator uses the smallest possible leak and says so.
  • EL stays at −70 mV. Changing Rin therefore changes the resting potential only slightly, through the shifting balance between the leak and the M current.
  • Ihold is a constant current injected throughout. Before every run the cell is settled at Ihold for 3 s, with no synaptic input, so the slow M current starts each sweep at its steady state. Every sweep starts from that same settled state, as though each were recorded after a long interval.
  • τm = Rin·Cm is shown as a derived value. With a single compartment it is also the time constant of the voltage response to a small step.

Rin at the holding potential is also reported. Depolarizing holding current recruits the M current and lowers the effective input resistance. That is physiology, not a discrepancy.

3. The electrode: Rs, bridge balance, pipette capacitance

I_cmd ──► pipette node P ──[ Rs ]──► cell V ──► membrane │ Cp to ground Cm dV/dt = (P − V)/Rs − I_membrane Cp dP/dt = I_cmd − (P − V)/Rs V_recorded = P − b · Rs · I_cmd (b = bridge balance, 0–1)

An ideal current source drives the pipette. In steady state all of the command current reaches the cell, so series resistance does not change the membrane potential. It changes what is recorded. The recorded voltage is taken at the pipette, so it carries an offset of I·Rs during a step (the bridge error), and the amplifier's bridge balance subtracts a set fraction of that offset. With pipette capacitance Cp > 0, Rs and Cp form a low-pass filter on the recorded voltage, and some of the current injected during fast voltage changes charges the pipette instead of the cell. Spikes in the record then look smaller and slower than the real ones. Cp stands for the capacitance left over after capacitance neutralization. At 0 pF, the default, Rs affects only the record's offset.

Every measurement below is taken on the true membrane potential, so electrode settings change what the traces show but not the F–I curve. To see how a bridge error would contaminate a threshold measurement, unbalance the bridge and compare the recorded trace with the true Vm (the “show true Vm” option).

4. PSCs

Both inputs are conductance-based: the current each event produces depends on the driving force (V − E). This is what makes the GABA reversal potential matter. A current-based input could not shunt, and could not change sign as the membrane crosses its reversal.

I_syn = g_glu(t)(V − E_glu) + g_GABA(t)(V − E_GABA) one event: g(t) = A · (exp(−t/τdecay) − exp(−t/τrise)), A chosen so the peak equals g_peak
  • Glutamate: AMPA-like, E_glu = 0 mV (fixed). Defaults 0.5 ms rise, 3 ms decay, 3 nS peak.
  • GABA: GABAA-like, E_GABA variable from −100 to 0 mV, default −80 mV. Defaults 0.5 ms rise, 10 ms decay, 3 nS peak.
  • Each input has a mean rate. Poisson timing draws exponentially distributed intervals. Regular timing gives clock-like events. At high rates a regular train approximates a tonic conductance.
  • Event times come from a seeded generator (mulberry32). The seed depends only on the barrage number, the input and the sweep index. So changing Rin, Cm, E_GABA or anything else about the cell replays exactly the same events, and any change in the response comes from the change you made. “New barrage” draws a new set.
  • A rise time of 0 gives an instantaneous rise and a single-exponential decay.

A mean rate of hundreds of hertz stands for many synapses converging on the cell: 1000 Hz is a thousand synapses each firing at 1 Hz, for example.

5. Integration

The integration follows NEURON's default fixed-step scheme. Each step of dt = 0.01 ms solves the linear system for V (and the pipette node, when Cp > 0) by backward Euler, with all conductances held at their values from the start of the step. The gates are then advanced at the new voltage by the exact exponential update for fixed V (Rush–Larsen), which is how the hh2 mechanism itself advances them. Backward Euler is unconditionally stable, which matters because Rs·Cp can be much shorter than dt. Traces are stored at 40 kHz (every 0.025 ms), like a digitizer.

The step is 0.01 ms rather than NEURON's usual 0.025 ms because the comparison below showed that at 0.025 ms spike times drift by several milliseconds over a second of repetitive firing. At 0.01 ms they stay within 0.2 ms.

The simulation runs in a Web Worker, in the browser. A 13-sweep, 1-second family takes about 0.2 s.

7. Checked against NEURON

The port was run against NEURON 9.0.2 executing the original ModelDB mechanisms (repository commit 8dfc13f): the same cell, a 3 s settle, then an 800 ms step, with dt = 0.01 ms and implicit Euler in both. Spike counts agree exactly at every amplitude, and every spike time agrees to within 0.2 ms:

The largest difference, 0.20 ms, is on the fifth spike of the 700 pA sweep, which comes 491 ms into a step that sits barely above threshold. Near threshold a long interspike interval amplifies any small numerical difference. Every other spike agrees to within 0.09 ms. This comparison is part of the test suite (src/core/oracle.test.ts), and tools/neuron_oracle.py regenerates the reference.

The electrode and synapse models are not part of the published cell, so NEURON cannot check them. The test suite checks them separately. With Cp = 0, changing Rs leaves Vm identical to the last bit. An unbalanced bridge offsets the record by exactly I·Rs. A single PSC peaks at exactly its set conductance. GABA reversing at the resting potential leaves Vm unmoved. Poisson trains have the requested rate.

8. When GABA excites

The simulator is named for this result. The table shows rheobase (bisected to 1 pA; 800 ms step) on the published cell, with clock-like GABA at 200 Hz, 3 nS peak, 0.5/10 ms, as E_GABA moves:

Two points come out of this table. First, depolarizing is not the same as excitatory. Between rest and about −50 mV, GABA depolarizes the cell and still makes it harder to fire, because the open conductance shunts the injected current. Second, the crossover sits at about −50 mV, some 11 mV below the −39 mV spike threshold. What matters is where Vm sits while the step charges the membrane toward threshold. Below the crossover, GABA pulls Vm down toward E_GABA; above it, GABA pushes Vm up. With Poisson rather than clock-like timing the numbers move by a few tens of pA from barrage to barrage, but the pattern holds. src/core/gaba.test.ts locks these values in.

9. What it leaves out

  • One compartment. There are no dendrites, no axon initial segment and no space clamp problem. Inputs arrive at the soma. Real distal inputs are filtered by the dendrites, and shunting depends on where inhibition lands.
  • Three active currents. There is no h-current (so no sag), no calcium or calcium-activated potassium currents (so no bursting and no medium or slow afterhyperpolarization), and no persistent sodium current. Threshold and firing pattern are the RS model's, not those of any particular recorded cell.
  • Fixed reversal potentials. E_GABA is a parameter, not an outcome. Chloride and bicarbonate do not move with activity. Sustained GABAA activity in a real cell can shift E_GABA, and this simulator does not.
  • AMPA and GABAA only. There is no NMDA voltage dependence, no GABAB, no short-term plasticity, and no correlations between inputs.
  • Current clamp only, with an idealized current source and a single lumped pipette capacitance. There is no amplifier bandwidth and no recording noise.
  • The default cell is in a high-conductance state, with Rin = 32 MΩ, as published. Raising Rin toward slice values makes it far more excitable.

10. Running it without a browser

The same code runs from a command line, with Node 22.18 or later and no build step:

git clone https://github.com/syncytium2/gaba_excites && cd gaba_excites && npm install node scripts/fi.ts # published cell, −200…1000 pA node scripts/fi.ts --rin 150 --cm 120 --steps 0,50,100,150,200 node scripts/fi.ts --gaba 200,3,0.5,10,-60 --regular --rheobase

It writes CSV to stdout, with the settings as # lines above the table.
